# Aula 4 - Formulários HTML5 e Bootstrap 5

Esta pasta reúne os materiais, exemplos práticos de formulários e um projeto de página responsiva utilizando Bootstrap 5.

## Arquivos

- `aula04.html` — interface prática do **Portal Acadêmico**, demonstrando uso de grid responsivo, navbar, cards de resumo e tabelas com Bootstrap 5.
- `aula04.css` — estilos complementares para a página do Portal Acadêmico.
- `formularios.html` — laboratório prático contendo diversos tipos de inputs nativos do HTML5, atributos de validação e organização em formulários.
- `formularios.css` — estilos para o laboratório de formulários.
- `Aula04.pdf` — material teórico e orientações da aula.

## Conteúdo Praticado

- **Inputs nativos do HTML5:** `text`, `search`, `number`, `range`, `email`, `url`, `tel`, `password`, `date`, `month`, `week`, `time`, `datetime-local`, `color`, `file`, `checkbox`, `radio`.
- **Validações e atributos:** `min`, `max`, `step`, `required`, `placeholder`.
- **Elementos estruturais de formulário:** `<form>`, `<label>`, `<fieldset>`, `<legend>`, `<select>`, `<textarea>`, `<datalist>`.
- **Bootstrap 5:** Sistema de grid (`row`, `col-*`), classes utilitárias, componentes de navegação, cards e tabelas estilizadas.

## Como Visualizar

1. Abra `aula04.html` ou `formularios.html` em seu navegador.
2. Ou utilize a extensão **Live Server** no VS Code para acompanhar as alterações em tempo real.
