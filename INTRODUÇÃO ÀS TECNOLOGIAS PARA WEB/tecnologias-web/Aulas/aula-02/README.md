# Aula 2 - Introdução ao CSS

Esta pasta contém exemplos e exercícios introdutórios de CSS usados na segunda aula.

## Arquivos

- `Aula02.pdf` — material teórico e slides oficiais da aula de introdução ao CSS.
- `index.html` — página com exemplos de seletores, box model, largura/altura e cards.
- `style.css` — folha de estilos demonstrando seletores e regras de CSS.

## Conteúdo abordado

- O que é CSS e sua relação com HTML
- Seletores por tag, classe e id
- Conceito de Box Model (margin, border, padding, content)
- Propriedades básicas: width, height
- Estrutura de cards e pequenos componentes visuais

## Como visualizar

1. Abra `index.html` nesta pasta.
2. Visualize em um navegador ou use Live Server no VS Code para ver alterações em tempo real.

## Sugestões de exercícios

- Tente adicionar um arquivo CSS externo e aplicar estilos às classes presentes em `index.html`.
- Modifique dimensões e margens para ver o efeito do box model.
