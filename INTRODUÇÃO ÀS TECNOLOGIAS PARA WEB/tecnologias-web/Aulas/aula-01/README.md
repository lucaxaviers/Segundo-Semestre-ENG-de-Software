# Aula 1 - HTML

Esta pasta contém os primeiros exemplos práticos de HTML da disciplina.

## Arquivos

- `Aula01.pdf` — material teórico e slides oficiais da aula de introdução às tecnologias web.
- `index.html` — página principal com diversos exemplos de tags e elementos HTML.
- `sobre.html` — página simples de exemplo para navegação interna.

## Conteúdo praticado

- Títulos (`h1` a `h6`)
- Parágrafos e formatação de texto
- Listas (`ul`, `ol`, `dl`)
- Links (`a`)
- Imagens (`img`)
- Tabelas (`table`, `tr`, `th`, `td`)
- Uso de atributos como `href`, `target`, `src`, `alt` e `colspan/rowspan`

## Como abrir

- Abra o arquivo `index.html` em um navegador;
- ou use o VS Code com a extensão Live Server para visualizar as alterações em tempo real.

## Exemplo de uso

A página principal demonstra vários elementos do HTML em uma única estrutura visual para facilitar a compreensão inicial da linguagem.

### Sugestão de estudo

- Repare como cada tag altera a visualização da página;
- Teste alterações simples no código para entender melhor o comportamento;
- Compare a página principal com a página `sobre.html` para entender links internos.
