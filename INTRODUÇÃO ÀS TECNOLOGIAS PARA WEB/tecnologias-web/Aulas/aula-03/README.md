# Aula 3 - Display e Flexbox

Esta pasta reúne os conceitos e exercícios práticos sobre modos de exibição (Display) e posicionamento moderno com **Flexbox**.

## Arquivos

- `index.html` — estrutura da página com seções demonstrativas de display (`block`, `inline`, `inline-block`), propriedades do Flexbox e vitrine de produtos.
- `style.css` — folha de estilos aplicando as regras de Flexbox, alinhamentos, espaçamentos e efeitos visuais nos componentes.
- `Aula03.pdf` — material teórico e slides da aula sobre Display e Flexbox.

## Conteúdo Praticado

- **Comportamentos de Display:**
  - `display: block` (quebra de linha e largura total)
  - `display: inline` (mesma linha, dimensão definida pelo conteúdo)
  - `display: inline-block` (mesma linha com controle de `width` e `height`)
- **Propriedades do Flexbox:**
  - `display: flex` (transformação em flex container)
  - `flex-direction` (`row`, `column`, `row-reverse`)
  - `justify-content` (`center`, `space-between`, `flex-end`)
  - `align-items` (`flex-start`, `center`, `flex-end`)
  - `gap` (espaçamento proporcional entre os itens flexíveis)
  - `flex-wrap: wrap` (quebra automática de linhas para elementos flex)
- **Vitrine Prática:** Construção de cards de produtos alinhados de forma flexível e responsiva.

## Como Visualizar

1. Abra `index.html` nesta pasta em seu navegador;
2. Ou utilize a extensão **Live Server** no VS Code para visualizar em tempo real.
