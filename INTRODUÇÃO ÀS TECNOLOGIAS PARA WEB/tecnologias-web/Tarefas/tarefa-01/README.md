# Tarefa 1 - Guia de Viagens pelo Brasil

Esta tarefa apresenta uma página exemplo com navegação interna, listas e uma tabela de sugestões de viagens.

## Arquivos

- `index.html` - página que contém o conteúdo da tarefa

## Objetivos da tarefa

- Praticar estruturação de conteúdo HTML (títulos, parágrafos, listas)
- Utilizar links internos para navegação na mesma página
- Criar e formatar tabelas simples para organizar informações

## Como visualizar

1. Abra `index.html` nesta pasta.
2. Abra em um navegador ou use Live Server no VS Code para ver a página.

## Sugestões de melhoria

- Adicionar estilos CSS para melhorar apresentação visual (cores, espaçamento)
- Tornar a tabela responsiva para visualização em dispositivos móveis
