# Tarefa 3 - Tech Academy

Esta tarefa consiste na criação de uma **Landing Page** moderna e institucional para a plataforma fictícia de cursos de tecnologia chamada **Tech Academy**, utilizando **HTML5** e **CSS3** puro.

## Arquivos

- `index.html` — estrutura da página inicial, contendo cabeçalho com navegação, seção principal (Hero) com chamada para ação (CTA), métricas em destaque e vitrine de cursos.
- `style.css` — estilos visuais aplicando alinhamentos com Flexbox, estilização de cartões (cards), botões com efeitos interativos e design responsivo.

## Objetivos da Tarefa

- Estruturar páginas institucionais com tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Implementar layout moderno com **Flexbox** para navegação e grade de cursos.
- Criar componentes visuais reutilizáveis (cards de cursos com título, descrição, carga horária e botão).
- Aplicar boas práticas de hierarquia tipográfica e contraste visual.

## Como Visualizar

1. Abra `index.html` nesta pasta diretamente no navegador;
2. Ou utilize a extensão **Live Server** no VS Code.
