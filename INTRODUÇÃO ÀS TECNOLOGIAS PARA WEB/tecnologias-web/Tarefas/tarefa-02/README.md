# Tarefa 2 - Currículo Web

Esta tarefa consiste no desenvolvimento de uma página pessoal e profissional de apresentação (currículo web), utilizando **HTML5** e **CSS3** puro.

## Arquivos

- `index.html` — página principal contendo o currículo estruturado com seções de perfil, contato, resumo profissional, formação acadêmica e habilidades.
- `style.css` — folha de estilos personalizada com layout em cards, estilização de tabelas, tipografia e espaçamentos.
- `foto-lucas.jpg` — imagem de foto de perfil utilizada no cabeçalho.

## Objetivos da Tarefa

- Praticar a estruturação de um documento completo e semântico em HTML5.
- Aplicar estilização personalizada em CSS3 (seletores, cores, bordas, sombras leves e espaçamentos).
- Organizar dados acadêmicos e profissionais através de tabelas estilizadas.
- Integrar mídias locais (foto de perfil) e links externos (GitHub, LinkedIn, Portfólio).

## Como Visualizar

1. Abra `index.html` nesta pasta diretamente no navegador;
2. Ou utilize a extensão **Live Server** no VS Code.
