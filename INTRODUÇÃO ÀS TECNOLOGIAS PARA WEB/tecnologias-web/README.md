## 📖 Sobre o Repositório

Este repositório reúne exemplos práticos, exercícios de fixação e projetos desenvolvidos ao longo das aulas da disciplina de Introdução às Tecnologias Web. O conteúdo abrange desde os fundamentos de estruturação com **HTML5** e regras de estilo com **CSS3/Flexbox**, responsividade e componentes com **Bootstrap 5**, manipulação dinâmica do **DOM** e validações com **JavaScript**, até a transição para o backend moderno utilizando **Node.js**, **TypeScript** e criação de **APIs RESTful** com **Express**.

## 🎯 Tarefas & Projetos

### 🧭 [Tarefa 1 — Guia de Viagens pelo Brasil](./Tarefas/tarefa-01/)
- **Objetivo:** Praticar a estruturação de conteúdo com HTML semântico.
- **Destaques:** Menu de navegação por âncoras na mesma página, listas aninhadas, organização de pacotes de viagem em tabelas e dicas para viajantes.
- **Acesso:** [`Tarefas/tarefa-01/index.html`](./Tarefas/tarefa-01/index.html)

### 📄 [Tarefa 2 — Currículo Web](./Tarefas/tarefa-02/)
- **Objetivo:** Desenvolver uma página de apresentação profissional estilizada com HTML5 e CSS3 puro.
- **Destaques:** Layout em cards com CSS customizado, foto de perfil, dados de contato com links externos, resumo de carreira, histórico acadêmico em formato tabular e lista de habilidades técnicas.
- **Acesso:** [`Tarefas/tarefa-02/index.html`](./Tarefas/tarefa-02/index.html)

### 🚀 [Tarefa 3 — Tech Academy](./Tarefas/tarefa-03/)

- **Destaques:** Header fixo com logotipo e menu, seção hero com chamada para ação (CTA) e estatísticas em destaque, grid de cards para cursos (HTML, CSS, JavaScript) com carga horária e rodapé institucional.
- **Acesso:** [`Tarefas/tarefa-03/index.html`](./Tarefas/tarefa-03/index.html)

## 🛠️ Tecnologias e Conceitos

- **HTML5:**
  - Elementos estruturais e semânticos (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
  - Formulários avançados (`<input type="date|range|color|search|email">`, `<datalist>`, `<fieldset>`, `<select>`).
  - Tabelas semânticas (`<thead>`, `<tbody>`, `<th>`, `<td>`, mesclagem com `rowspan` e `colspan`).
- **CSS3:**
  - Modelo de Caixa (*Box Model*), dimensionamento e espaçamentos.
  - Tipografia moderna, cores em variáveis e efeitos de transição/hover em botões e links.
  - Flexbox e alinhamento de componentes (`flex-direction`, `justify-content`, `align-items`, `gap`, `flex-wrap`).
- **Bootstrap 5:**
  - Sistema de Grid responsivo, classes utilitárias de espaçamento e tipografia.
  - Componentes prontos: Navbar, Cards, Tabelas estilizadas e formulários (`form-control`, `form-select`).
- **JavaScript & DOM:**
  - Seleção e manipulação de elementos HTML via `document.querySelector` e `getElementById`.
  - Escuta de eventos (`click`, `submit`), prevenção do reload nativo (`preventDefault()`).
  - Validação de dados em interface, aplicação de estados com `classList` e montagem de JSON.
- **Node.js, TypeScript & Express:**
  - Execução de JavaScript no servidor com o runtime Node.js.
  - Tipagem estática com TypeScript, interfaces, tipos literais e compilação para JavaScript (`tsc`).
  - Desenvolvimento de APIs RESTful estruturadas em recursos e endpoints (`GET`, `POST`, `PUT`, `DELETE`).
  - Manipulação de `req.params`, `req.query`, `req.body` com middleware `express.json()`.
  - Tratamento de status codes HTTP padronizados (`200`, `201`, `400`, `404`, `500`).

## ⚡ Como Executar

### 1. Clonar o Repositório
```bash
git clone https://github.com/lucaxaviers/tecnologias-web.git
cd tecnologias-web
```

### 2. Aulas de Frontend (Aulas 1 a 5 e Tarefas)
- Abra o repositório no **VS Code** (`code .`).
- Com a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer), clique com o botão direito no arquivo `index.html` da aula desejada e selecione **"Open with Live Server"**.
- Ou simplesmente abra o arquivo `.html` diretamente no seu navegador padrão.

### 3. Aulas de Backend & APIs (Aulas 6 e 7)
1. Navegue até a pasta da aula desejada:
   ```bash
   cd Aulas/aula-07
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor em modo de desenvolvimento:
   ```bash
   npm run dev
   ```
4. O servidor iniciará em `http://localhost:3000`. Utilize a extensão **REST Client** / **Thunder Client** com o arquivo `requests.http` para testar os endpoints!
