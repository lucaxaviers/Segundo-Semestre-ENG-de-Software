# 🎓 Engenharia de Software — 2º Semestre

Repositório dedicado ao armazenamento e versionamento de todos os projetos, trabalhos e listas de exercícios desenvolvidos durante o **Segundo Semestre** do curso de Engenharia de Computação.

---

## 📚 Disciplinas Cursadas

Neste repositório, você encontrará diretórios organizados por matéria, contendo todo o material prático e teórico desenvolvido ao longo do semestre:

- **💻 Algoritmos e Linguagem de Programação:** Lógica avançada e construção de algoritmos estruturados.
- **🗄️ Banco de Dados II:** Modelagem relacional complexa, queries avançadas e otimização.
- **📐 Engenharia e Elicitação de Requisitos:** Técnicas de levantamento, documentação e análise de requisitos de software.
- **🏗️ Estrutura e Recuperação de Dados I:** Estruturas de dados fundamentais (pilhas, filas, listas, árvores) e algoritmos.
- **🌐 Introdução às Tecnologias para Web:** Fundamentos de front-end (HTML, CSS, JS) e arquitetura web.

---

## 🛠️ Tecnologias Utilizadas
*As tecnologias variam de acordo com a disciplina, mas o escopo principal engloba:*
- **Linguagens:** C/C++, Java, JavaScript, SQL
- **Ferramentas & Banco de Dados:** MySQL, Git, VS Code
